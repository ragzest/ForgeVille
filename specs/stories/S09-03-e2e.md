# S09-03 — End-to-end walkthrough

Status: done
Epic: [E09](../epics/E09-vertical-slice.md)
Depends on: S09-01

## Story

As a maintainer, I want one automated walkthrough so navigation and a failing workflow cannot silently break.

## Acceptance criteria

- Playwright starts the app and opens the 2D alternative.
- The test selects the `qa-failure` scenario (the failing-check demo), opens the related pull request, and asserts merge is refused with the failed check named.
- The test opens an agent panel and sees the simulated terminal label.
- The test rides the elevator to a vacant floor and back, and the team is present again (extends `e2e/building.spec.ts`).
- The test asserts a canvas element exists when WebGL is available in the Playwright browser. If the runner has no WebGL, the test still passes through the documented 2D path and records that limitation in the README later.
- The test does not call GitHub or an external agent endpoint. Network requests to those hosts fail the test if any appear.

## Verification

- `npm run test:e2e`

## Out of scope

Visual screenshot approval.
