# E07 — QA lab and pull-request theatre

Status: done

## Outcome

The QA corner and a detail panel explain a mock pull request, its checks, findings, and why merge is allowed or refused.

## Stories

- [S07-01](../stories/S07-01-pr-panel.md)
- [S07-02](../stories/S07-02-merge-actions.md)

## Done when

- Passing and failing scenarios render different check timelines from data.
- Merge is disabled or refused with reasons when policy fails.
- A permitted merge updates the task, pull request, events, and mission-control metrics together.

## Out of scope

Real GitHub merge, real browsers for the "browser test" row, or image generation. Screenshots are labelled placeholders.
